## Conjunto de Slides (Estrutura)

Este documento contém a apresentação completa do projeto FairPlay, uma aplicação móvel desenvolvida para facilitar o gerenciamento e a reserva de quadras esportivas.

A apresentação aborda o problema identificado, os objetivos do projeto, o público-alvo, as principais funcionalidades implementadas, a arquitetura do sistema, os desafios enfrentados durante o desenvolvimento e os resultados obtidos pela equipe.

O material foi elaborado como parte das atividades acadêmicas do curso de Análise e Desenvolvimento de Sistemas da PUC Minas.
